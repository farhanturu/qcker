## 1.1 Seccomp — `crates/qcker-runtime/src/seccomp.rs`
Replace the no-op `apply_seccomp_filter()` (currently `tracing::debug!("Would block {} syscalls"); Ok(())`) with a **real BPF denylist** installed into the kernel.

- Add `const AUDIT_ARCH_X86_64: u32 = 0xC000003E;` (absent from libc 0.2.189).
- Add helpers `bpf_stmt(code, k)` / `bpf_jump(code, k, jt, jf)` returning `libc::sock_filter`.
- Add `fn syscall_nr(name: &str) -> Option<i32>` mapping names → `libc::SYS_*` (mount, ptrace, reboot, pivot_root, kexec_load, swapon, unshare, etc.). Unknown names skipped.
- `install_filter(blocked_nrs: &[i32]) -> Result<()>`: builds the classic denylist program:
  `[LD arch] [JEQ x86_64→skip kill / else→kill] [LD nr] (for each: [JEQ nr→ERRNO] ) [RET ALLOW] [RET ERRNO|EPERM]`, then `libc::syscall(SYS_seccomp, SECCOMP_SET_MODE_FILTER, 0, &mut sock_fprog)`; propagate non-zero as `QckerError::Seccomp`.
- `apply_seccomp_filter()`: resolve its syscall list to numbers, call `install_filter`.
- `apply_profile(profile)`: resolve `profile.syscalls` (action==Errno) → numbers → `install_filter`; honor default_action.
- **`apply_default_profile()`**: on filter error **propagate `Err`** (remove the `Ok(())`-on-error swallow). NO_NEW_PRIVS stays.
- Tests: `test_bpf_filter_shape` (build program, assert length/instructions — no kernel install); `test_syscall_nr_resolution`; keep existing `#[ignore]` root test, add an `#[ignore]` fork-based test verifying a blocked syscall returns EPERM.
